# Summary evidence / 总结依据

[Evidence ledger / 来源记录](evidence.json) binds representative papers to this track, scope, task, catalog record and available PDF evidence. Contributions retained from earlier reading notes are distinguished from topic descriptions. Evaluation guidance and opportunities are editorial synthesis; extracting a PDF does not imply a complete reading.

[Summary sources / 总结正文](../../summaries/) are rendered above each task list. Main/Findings and Core/Application are summarized separately. Empty tasks explicitly say 暂无收录论文.
