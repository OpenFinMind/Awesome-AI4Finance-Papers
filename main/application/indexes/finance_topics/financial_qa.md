### 中文

**研究问题与子方向。** 围绕金融问题寻找证据并生成事实答案、数值答案或可执行推理。文本与表格联合推理、跨文档问答和多轮对话需要不同的证据对齐方式。

**当前收录与方法。** 本页仅总结 Main / application 中的论文。当前较常见的子分类：Numerical Calculation and Program Reasoning / 数值计算与程序推理 (52); Financial Factual QA / 金融事实问答 (10); Table-and-Text QA / 表格与文本联合问答 (7); Chart and Multimodal QA / 图表及多模态问答 (4); Conversational Financial QA / 对话式金融问答 (2)。已标注的方法：Language Models & LLM / 语言模型与LLM (46); Retrieval & RAG / 检索与RAG (14); Uncertainty & Robustness / 不确定性与鲁棒性 (11); Representation Learning / 表征学习 (9); Tabular Learning / 表格学习 (6)。这些是多标签篇数，不能直接相加，也不表示性能排名。

**数据与评测。** 分别检查答案、推理程序、证据引用及跨表跨文档一致性。 代表论文的摘要、金融关联证据及原文链接见 [1](../finance_notes/2026.acl-long.974.md) · [2](../finance_notes/2026.acl-long.213.md) · [3](../finance_notes/2026.acl-long.2054.md) · [4](../finance_notes/2026.acl-long.2176.md)；不同数据与指标不合并为统一数值结论。

**研究机会（编辑判断）。** 将答案正确性、数值单位、推理步骤和引用忠实性分别验证，研究拒答与不完整用户信息下的可靠性。
