### 中文

**当前收录与方法。** 本页仅总结 Main / application 中的论文。当前较常见的子分类：Trading Strategies and Buy/Sell Decisions / 交易策略与买卖决策 (29); Financial Agents and Multi-Agent Decisions / 金融智能体与多主体决策 (27); Market Making and Quoting / 做市与报价策略 (4); Dynamic Hedging / 动态对冲 (1); Order Execution / 订单执行 (1)。已标注的方法：Language Models & LLM / 语言模型与LLM (27); Uncertainty & Robustness / 不确定性与鲁棒性 (18); Optimization & Numerical Methods / 优化与数值方法 (13); Reinforcement Learning / 强化学习 (8); Representation Learning / 表征学习 (7)。这些是多标签篇数，不能直接相加，也不表示性能排名。

**数据与评测。** 区分离线预测与闭环决策，显式计入交易成本、延迟和市场冲击。 代表论文的摘要、金融关联证据及原文链接见 [1](../finance_notes/aaai-2026-40222.md) · [2](../finance_notes/2026.acl-long.281.md) · [3](../finance_notes/2026.acl-long.1464.md) · [4](../finance_notes/2026.emnlp-main.1871.md)；不同数据与指标不合并为统一数值结论。

**研究机会（编辑判断）。** 用闭环实验和消融分离信息、推理、工具与执行贡献，纳入延迟、市场冲击和失败恢复。
