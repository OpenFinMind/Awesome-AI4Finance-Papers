**当前收录与方法。** 本页仅总结 Findings / application 中的论文。当前较常见的子分类：Financial Understanding and Multimodal Evaluation / 金融理解及多模态评测 (3); Financial Datasets and Task Benchmarks / 金融数据集与任务基准 (2)。已标注的方法：Language Models & LLM / 语言模型与LLM (5)。这些是多标签篇数，不能直接相加，也不表示性能排名。

**研究机会（编辑判断）。** 检查污染、标注、用户场景和预算敏感性，研究静态得分与实际金融工作表现之间的联系。

### English

**Problem and subdirections.** The main contribution is a dataset, benchmark, evaluation environment, protocol or capability audit. Coverage, construction and evaluation design are research objects; merely using an existing benchmark is insufficient.

**Current coverage and methods.** This page covers only Findings / application. Frequent subcategories: Financial Understanding and Multimodal Evaluation / 金融理解及多模态评测 (3); Financial Datasets and Task Benchmarks / 金融数据集与任务基准 (2). Recorded methods: Language Models & LLM / 语言模型与LLM (5). Counts overlap and are not performance rankings.

**Data and evaluation.** Inspect coverage, contamination, annotation quality, evaluation budget and limits of metric extrapolation. Representative abstracts, financial evidence and original sources are linked at [1](../finance_notes/2026.findings-acl.1675.md) · [2](../finance_notes/2026.findings-emnlp.2304.md) · [3](../finance_notes/2024.findings-acl.478.md) · [4](../finance_notes/2024.findings-emnlp.972.md). Results from incompatible data or metrics are not pooled.

**Research opportunities (editorial).** Check contamination, annotation, user scenarios and budget sensitivity, and study the connection between static scores and financial work.
