# Awesome AI4Finance Papers

[English](README.md) | [中文](README.zh-CN.md)

AI for Finance long papers organized by financial task, subcategory and technical method. Maintained by [OpenFinMind](https://github.com/OpenFinMind).

## Scope

Covers finance-related **long papers** from **ICML, ICLR, ACL, EMNLP, NeurIPS and AAAI Main**, **KDD Research Track**, and **ACL / EMNLP Findings**, within **2017–2026**. Includes financial core research and financial applications. Short papers are excluded.

## Classification

- **Core / 金融核心研究**: the main research problem or contribution concerns finance. / 主要研究问题或贡献直接面向金融。
- **Application / 金融应用**: finance is a substantive application of a general method. / 金融是通用方法的实质性应用。

Complete subcategories and boundaries are defined in each collection’s classification guide. Insufficiently supported refinements remain pending. Financial Risk and Financial Safety are separate tasks.
